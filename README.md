# Aula_MrP
Proyecto de Microcontroladores para la asignatura de Sistemas Electrónicos para Automatización, de 4º de GIERM
- Rubén Gutierrez Ortega
- Manuel García Martín

¡En el aula de MrP podrás aprender sobre diversos sensores de manera cómoda y divertida!

Este proyecto es un sistema interactivo que mezcla lecciones teóricas con demostraciones de funcionamiento para acercar la electrónica al usuario.
