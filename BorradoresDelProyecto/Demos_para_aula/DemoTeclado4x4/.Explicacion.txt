Para la demostración del teclado matricial se ha optado por recrear un telefono, en este se van introduciendo números por teclado hasta que se pulse # que realiza la llamada (o * que borra el número introducido).
Cuando llamas sale un mensaje personalizado si el número está registrado, en caso contrario responde un mensaje genérico diciendo que no conoce el contacto.

Se ha necesitado de 2 funciones para la demostración.

Una simple llamada "DibujarTeclaVisual" que permite dibujar un tecla del movil que aparece en la interfaz de forma vistosa:
    void DibujaTeclaVisual(int x, int y, char *texto){
        // Fondo de la tecla
        ComColor(55, 75, 90);
        ComRect(x-15, y-9, x+15, y+9, 1);

        // Borde
        ComColor(180, 200, 210);
        ComLineWidth(1);
        ComRect(x-15, y-9, x+15, y+9, 0);

        // Numero
        ComColor(255, 255, 255);
        ComTXT(x, y-8, 20, OPT_CENTERX, texto);
    }

Y la función principal "Telefono"

Primero se declaran las variables propias de la función:
// Declaración de variables
    static char numeroMostrado[TAM_CODIGO + 1U] = "";
    static char personaLlamada[32] = "Sin llamada";
    static char mensajePersona[64] = "";

Tras esto se lee el estado del teclado.
// Se consulta el estado del teclado
    ev = TECLADO_Actualizar();

Dependiendo del valor de ev se realizará una acción distinta (se diferencia entre teclado pulsado o no)

Si está pulsado se lee la tecla registrada y dependiendo de su valor se realizará una acción diferente.

En el caso de un valor numérico suena una nota aleatoria (dentro de un rango) y se añade a la cadena del numero marcado

Si se lee * suena una nota aguda y limpia toda la cadena

Por último, si pulsa # se "llama", de esta forma se evalua la cadena y se responde con un mensaje preparado. Al final se limpia la cadena

En el caso de dejar de pulsar (o no haber pulsado) se silencia la nota que se estaba tocando
// Se registra la tecla o se deja de reproducir el sonido
    switch(ev){
    case TECLADO_EV_PULSADA:
        tecla = TECLADO_Tecla();    // Tecla pulsada

        if(tecla >= '0' && tecla <= '9'){
            TocaNota(S_XILO, (rand() % 11) + 48);
            if(n < TAM_CODIGO){
                codigo[n++] = tecla;
                codigo[n] = '\0';

                strcpy(numeroMostrado, codigo);
                strcpy(personaLlamada, "Marcando...");
                strcpy(mensajePersona, "");
            }
        }

        // Borrar
        else if(tecla == '*'){
            TocaNota(S_XILO, 70);
            n = 0;
            codigo[0] = '\0';
            numeroMostrado[0] = '\0';
            strcpy(personaLlamada, "Sin llamada");
            strcpy(mensajePersona, "");
        }

        // Realizar llamada
        else if(tecla == '#'){
            TocaNota(S_XILO, 60);
            codigo[n] = '\0';

            if(n == 0){
                strcpy(personaLlamada, "Sin numero");
                strcpy(mensajePersona, "Introduce un numero");
            }else if(strcmp(codigo, "0000") == 0){
                strcpy(personaLlamada, "Contacto 0000");
                strcpy(mensajePersona, "Hola! Soy el contacto 0000");
            }else if(strcmp(codigo, "01") == 0){
                strcpy(personaLlamada, "Contacto 01");
                strcpy(mensajePersona, "Buenos dias! Quien eres?");
            }else if(strcmp(codigo, "34231") == 0){
                strcpy(personaLlamada, "MrP");
                strcpy(mensajePersona, "Hola MrP! Que tal?");
            }else{
                strcpy(personaLlamada, "Numero desconocido");
                strcpy(mensajePersona, "No conozco este numero");
            }

            n = 0;
            codigo[0] = '\0';
        }
        break;

    case TECLADO_EV_SOLTADA:
        FinNota();
        break;

    default:
        break;
    }
